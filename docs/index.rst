MecaPy Documentation
====================

Welcome to MecaPy, a Python library for mechanical engineering calculations.

MecaPy provides tools and utilities for analyzing and designing mechanical components including:

- **Beams** - Beam analysis and design
- **Wheels** - Wheel design and analysis
- **Gears** - Gear design and analysis
- **Bearings** - Bearing selection and analysis
- **Bolts** - Bolt design and stress analysis
- **Welds** - Weld design and analysis
- **Shafts** - Shaft design and analysis
